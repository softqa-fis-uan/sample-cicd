# Implementación en Java usando Spring Boot

Esta carpeta contiene la implementación del API definido en [`greetings.yaml`](../greetings.yaml). Puede ver el swagger de la aplicación en (http://localhost:5001/docs)

Para correr la aplicación usar:

```bash
./gradlew bootRun
```

para correr las pruebas:

```bash
./gradlew check
```
