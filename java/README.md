# Implementación en Java usando Spring Boot

Esta carpeta contiene la implementación del API definido en [`greetings.yaml`](../greetings.yaml). Puede ver el swagger de la aplicación en (http://localhost:8080/docs)

Para correr la aplicación usar:

```bash
./gradlew bootRun
```

para correr las pruebas:

```bash
./gradlew check
```

### Flujo de un request: `POST /greetings`

```mermaid
sequenceDiagram
    actor Client
    participant MVC as Spring MVC
    participant Ctrl as GreetingsController
    participant UC as CreateGreeting
    participant Res as LanguageResolver
    participant Repo as InMemoryLanguageRepository<br/>(via LanguageRepository port)
    participant Profile as LanguageProfile
    participant Advice as ApiExceptionHandler

    Client->>MVC: POST /greetings {name, language}
    MVC->>MVC: deserialize into CreateGreetingRequest and validate (@Valid)
    alt malformed JSON or missing fields
        MVC-->>Client: 400 problem+json (ResponseEntityExceptionHandler)
    else valid request
        MVC->>Ctrl: createGreeting(request)
        Ctrl->>UC: execute(name, language)
        alt blank name
            UC-->>Advice: throw InvalidNameException
            Advice-->>Client: 400 problem+json
        else name is present
            UC->>Res: resolve(language)
            Res->>Res: normalize code ("ES-co" becomes "es")
            Res->>Repo: findByCode(code)
            Repo-->>Res: Optional of LanguageProfile
            alt language supported
                Res-->>UC: LanguageProfile
                UC->>Profile: greet(name)
                Profile-->>UC: Greeting
                UC-->>Ctrl: Greeting
                Ctrl-->>MVC: ResponseEntity with the Greeting DTO
                MVC-->>Client: 200 {greeting, language}
            else unsupported language
                Res-->>Advice: throw UnsupportedLanguageException
                Advice-->>Client: 400 problem+json
            end
        end
    end
```
